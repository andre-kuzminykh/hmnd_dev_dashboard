## Как данные попадают в БД (важно для новой недели)

1. БД (`data/hmnd.db`) **эфемерна** и в git не хранится — она пересобирается из файлов
   в `sources/` командой `python -m scripts.sync` (или `scripts.reset`).
2. На каждого провайдера `sync` берёт **самый свежий файл** — по дате в имени
   (`*_YYYYMMDD.json`). Файлы постарше игнорируются (их можно удалить или оставить как бэкап).
3. Период загрузки берётся из `_meta.rangeStart/rangeEnd` внутри JSON. Загрузчик
   идемпотентен: `DELETE` событий провайдера за этот период → `INSERT`. Повторная
   загрузка того же файла не плодит дубликаты.

## Как ДОБАВИТЬ новую неделю, чтобы «в БД всё было правильно»

Новые выгрузки **кумулятивные** — каждый файл уже содержит всю прошлую историю
(`_meta.rangeStart = 2026-02-12`) плюс новую неделю. Поэтому всё просто:

1. Положи **три** новых файла в `sources/` с датой в имени **позже** `20260515`
   (напр. `Anthropics_20260522.json`, `Cursor_20260522.json`, `OpenAI_20260522.json`).
2. `sync` возьмёт самый свежий файл на каждого провайдера и перетрёт период целиком —
   в БД окажется ровно содержимое нового файла (полная история + новая неделя), без задвоения.
3. Старые `*_20260515.json` можно удалить или оставить (они игнорируются). Если важно место —
   перенеси их в `backups/`.

⚠️ Проверь, что `_meta.rangeStart` нового файла = `2026-02-12` (тот же старт, что и сейчас).
Если новый файл вдруг начнётся позже, история до его старта в БД не попадёт.

После добавления — пересобери и сверь:
```bash
python -m scripts.reset --days 200    # полная пересборка из sources/
```
Числа за `2026-02-12 → 2026-05-13` должны совпасть с `SNAPSHOT_METRICS.json` (новый файл
их содержит), плюс добавятся события новой недели.

## Восстановление

Вернуть исходные файлы из бэкапа:
```bash
cp backups/2026-05-28/sources/*.json sources/
cp "backups/2026-05-28/sources/git_repos.txt" sources/
python -m scripts.reset --days 200      # пересобрать БД из источников
```

Поднять материализованный снимок БД напрямую (без пересборки):
```bash
gunzip -c backups/2026-05-28/hmnd_snapshot.sql.gz | sqlite3 data/hmnd.db
```

## Проверка целостности бэкапа
```bash
cd backups/2026-05-28
python3 - <<'PY'
import hashlib, json, pathlib
m = json.load(open("MANIFEST.json"))
bad = 0
for rel, meta in m["files"].items():
    h = hashlib.sha256(pathlib.Path(rel).read_bytes()).hexdigest()
    if h != meta["sha256"]:
        print("MISMATCH:", rel); bad += 1
print("OK" if not bad else f"{bad} mismatch(es)")
PY
```
