§3.1 Week 1 · Connect Jira → unlock ROI measurement

Data source gap. Jira is not yet integrated in the dashboard pipeline. AI spend, Git, and Cursor/Anthropic/OpenAI telemetry are live; Jira (and PR review data) are the only missing pieces. Until Jira ingestion lands, ROI metrics that depend on closed-ticket counts are baseline-only and cannot be tracked over time. HMND-AI-1 below establishes that integration — it is the prerequisite for everything else.

§3.3 Direction A · Environment rollout · what happens each week of the month

Week 1 · Spec

Specification

  • • Feature → User Flow → Use Case
  • • FR / NFR + acceptance criteria
  • • Tests-by-4-layers (Infra / Data / Service / AI)
  • • Update AGENTS.md if scope-affecting
  • • Exit: SPEC merged + tests defined
Week 2 · Test & Dev

TDD per layer

  • • Write tests first (red)
  • • Claude Code multi-file implementation
  • • Cursor IDE for targeted edits
  • • PR review + CI green
  • • Exit: feature merged with tests passing
Week 3 · Refactor

Debt paydown

  • • Code review of recent merges
  • • Refactor duplication / dead code
  • • Address linter / pre-commit drift
  • • Update READMEs & ADRs
  • • Exit: no open code-quality alerts
Week 4 · Env & Monitor

Environment & analytics

  • • CI workflow updates
  • • Dashboards refresh · ROI metrics
  • • Budget alert review
  • • Prompt-regression eval run
  • • Exit: monthly visibility report shipped

§3.4 Direction B · Education · 8 weekly lectures

One lecture per week (60-min recorded session + 30-min Q&A + 1 take-home exercise reviewed in the next session). Champion-led — named in each card. Target audience: all 87 active engineers.

L1
Week 2

Spec discipline

Feature → User Flow → Use Case → FR/NFR → Tests-by-4-layers (Infra · Data · Service · AI). The F-17 template, applied.

Lead: AI lead · Take-home: rewrite one feature spec

L2
Week 3

Test pyramid that catches AI bugs

Unit / contract / integration / E2E. Snapshot tests for AI-generated output. Why: hmnd_wholebody (4 tests / 60k LoC) and hmnd_firmware (0 tests) need a floor.

Lead: hmnd_robot owner · Demo: 401-test layout

L3
Week 4

AGENTS.md craft

Anatomy of hmnd/AGENTS.md: TL;DR, architecture rule, language-specific anti-patterns, build/test commands. Why: 9/14 hmnd modules + all of hmnd-cloud have no AGENTS.md.

Lead: Atindra · Take-home: AGENTS.md for one module

L4
Week 5

Prompt-regression evals

5–10 canonical tasks run quarterly against current AGENTS.md / .cursor/rules. Why: single biggest cross-cutting gap; AGENTS edits silently break AI behaviour today.

Lead: AI lead · Take-home: write 2 eval tasks

L5
Week 6

Safe Terraform with AI

Plan, never apply from AI. Per-domain blast-radius matrix. tflint / tfsec / checkov as PR gate. Why: hmnd-cloud is highest-blast-radius repo in scope.

Lead: matakan · Demo: PR-validation workflow

L6
Week 7

Agent workflows that ship code

Claude Code multi-file refactors, Cursor Agent for boilerplate, when to drop to Tab. Why: Eugene's pattern (Claude $2.3k + 1.6k commits) is the gold standard.

Lead: Eugene · Demo: one Claude Code session end-to-end

L7
Week 8

Cost discipline & routing

$0.001 → $0.37/req is a 370× spread. When o-series is right, when it's habit. Why: 3 users burn $1k/mo on o-series for routine queries.

Lead: Eng Manager · Demo: routing policy in action

L8
Week 9

Governance & review rules

CODEOWNERS · branch protection · AI-assist PR template · audit policy for 21+-file commits (15% of total). Why: the line between "AI-accelerated" and "AI-incident" team is process.

Lead: CTO + Eng Manager

Conclusion

8 lectures × 8 weeks = the full AI-Native curriculum. Weeks 2–5 are foundational (Spec, Test, AGENTS, Evals). Weeks 6–7 deepen technique (IaC + agent workflows). Weeks 8–9 close on governance + cost discipline. Total cost: ~12 prep-hours + 12 attendee-hours × 87 engineers.
