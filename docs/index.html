§A.2 · Glossary

▶
AGENTS.md
Markdown file at repo / module root that tells AI agents the repo's conventions, anti-patterns, build/test commands. The most powerful single guardrail.
CODEOWNERS
GitHub file pinning paths to owner teams. Forces human reviewer per path; blocks AI auto-merge.
Bug-fix rate
Share of commits whose subject matches a bug-fix regex. Directional, not semantic.
Bus factor
Number of people who, if "hit by a bus", would orphan the module. 1 = highest risk.
Pareto / 80-20
A few users account for most spend. HMND: top-10 = 63%. Budget governance on ~10 people catches most drift.
Cohort
A specific group defined by a query. "140 active humans" (30d AI users) ≠ "206 lifetime devs" (segment universe).
Champion (Q1)
An engineer with HIGH AI spend AND HIGH Git output. The pattern to document and scale.
Synthesised event
A Claude Code event reconstructed from Cursor's agent_completions. Appears as a uniform 56-event signature per user.
Identity merge
Collapsing one human's @thehumanoid.ai and @skl.vc rows into a single user_id. Done 2026-05-16 for 20 people.
Prompt-regression eval
A canonical task set run against the current AGENTS.md / .cursor / .claude content. Detects when instruction changes silently break AI. HMND has zero today.

§A.3 · Methodology & data freshness

▶

Window: 30-day AI spend = 2026-04-16 → 2026-05-16. Git data = unshallowed clones of the 3 core repos on 2026-05-16. Identity merge applied 2026-05-16 afternoon.
