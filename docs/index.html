1 · Model-routing policy
Default mid-tier, escalate to reasoning only on demand. Экономия: $1.5-3k/мес.

Не cap, а early-warning. Покрывает 80% cost drift через ~10 человек.

Oleg, atin, Eugene, Richard, Sam Pfeiffer — записать workflow, опубликовать playbook.

Pair с champions на 1 sprint каждого. Productivity left on the table.
5 · Connect Jira + PR + Incidents для ROI proof
AI ↔ Git уже подключён. Не хватает: PR review (time-to-merge, review comments, reverts) + Jira (cycle time, closures, incidents). Только тогда возможна метрика «cost per merged PR» / «cost per closed ticket».
